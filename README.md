# 技术知识图谱

一个在浏览器里用的个人知识图谱：从 LoRa、NFC、抓包、ESP32 出发，覆盖无线通信、网络与安全、计算机基础、嵌入式、物联网、软件开发、AI 与视觉、无人机与控制、机械工程 9 个领域，900 多个词条。

**在线使用：** https://jackdhch.github.io/tech-knowledge-graph/

## 怎么用
- 右栏顶部选一支笔（◐ 听说过 / ● 熟悉 / ★ 关注 / 清除），在图上或「词条目录」里点一下就标上，同一支笔再点一次取消。
- 颜色＝领域，大圆＝领域，小圆＝概念，方块＝具体东西（芯片、软件、产品）。
- 标过的词会出现在图上；每次「拓展」后，没标也没碰过的节点会先变灰、再收起，图不会越来越乱。
- 搜索框能直接找词。

## 你的数据
- 标记只存在**你自己的浏览器**里（localStorage），不会上传到任何地方，别人也看不到。
- 换浏览器或想备份：右下角「导出 JSON」存一个小文件，在别处「导入 JSON」合并回来（只加不减）。
- 清了浏览器数据会丢标记，记得偶尔导出一下。
